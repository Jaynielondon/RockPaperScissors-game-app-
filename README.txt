Rock Paper Scissors GUI Game

This project uses Python and Tkinter to create a Rock Paper Scissors game with a graphical user interface. The user selects rock, paper, or scissors using buttons, and the computer randomly chooses an option. The program then determines the winner and keeps score.

Language Used:
Python

Libraries Used:
tkinter
random

Main Skills Practiced:
- GUI development
- buttons and text widgets
- functions
- global variables
- conditional statements
- random choices
- score tracking
- game logic

Project Features:
- Interactive GUI game window
- Rock, Paper, and Scissors buttons
- Random computer choice generation
- Score tracking for user and computer
- Displays game results after each round
- Uses game logic to determine winners
